# HealthConnect – Data Analytics

## Project Overview

HealthConnect is a healthcare analytics project focused on understanding patient appointment attendance and no-show behaviour.

The project uses data analytics to identify patterns that can support better appointment management and informed decision-making.

## Week 5 – Data Analytics

Week 5 focused on moving from initial exploration into the implementation stage.

### Work Completed

- Data preparation and validation
- Exploratory Data Analysis (EDA)
- KPI development and analysis
- No-show pattern analysis
- Interactive Power BI dashboard development
- Dashboard testing and validation
- Initial business recommendations

## Key KPIs

| KPI | Result |
|---|---:|
| Total Appointments | 5,000 |
| Attendance Rate | 46.28% |
| No-Show Rate | 48.46% |
| Cancellation Rate | 5.26% |
| Reminder Coverage | 72.68% |

## Key Findings

- No-shows accounted for 48.46% of appointments.
- Longer booking lead times were associated with higher observed no-show rates.
- Previous no-show history was associated with higher current no-show rates.
- Appointments without reminders had a higher observed no-show rate.
- Greater distance to the clinic was associated with higher observed no-show rates.
